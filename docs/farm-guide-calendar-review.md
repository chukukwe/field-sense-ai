# FarmPal crop calendar: published-source review

Reviewed 26 October 2026. This is a desk review of published guidance, not independent agronomist approval, a measured accuracy score or field validation. Sources were checked for usable dates, geography, production method and variety limits. Search-indexed source passages were used where the publisher PDF could not be fetched directly; those access limits are recorded below. No third party was contacted.

## Decisions

| Crop | Decision | Evidence and limit |
| --- | --- | --- |
| Maize | Retain existing scoped windows | IITA northern maize guide, printed p7; NAERLS SAMMAZ 63 humid-zone guidance. No expansion to other varieties or zones in this pass. |
| Groundnut | Retain existing scoped windows | ICRISAT/FMARD guide, Table 1 and sowing chapter. Irrigation and named SAMNUT limits remain required. |
| Cassava | Add conditional windows | IITA illustrated commercial guide, printed p8 Step 6. Humid Forest entries require the site's two-rainy-season pattern. Guinea savanna entries require dependable onset and suitable local material. No dates inferred for coastal subzones, Derived Savanna, Sudan, Sahel or highlands. |
| Soybean | Add selected savanna windows | IITA revised 2020 guide, printed p7 Table 2. The table overlaps a Northern Guinea–Sudan row with a separate Sudan row: use the explicit Sudan row there. Established rains and suitable variety remain required. |
| Cowpea | Add limited northern windows | IITA 2020 northern guide, printed p7 Table 1. Only the determinate early/medium branch is used. Its Southern Guinea late-August advice and unusual rainfall description need local review before publication. NAERLS reproduces this table's timing; this is not an independent field validation. |
| Rice | Withhold regional dates | NAERLS FARO 67 article covers lowland/direct-seeding methods but establishes no scoped month range. AfricaRice describes farm-specific advice requiring growing-environment inputs. Need upland/lowland, water regime, variety and nursery/direct-seeding distinction. |
| Sorghum | Withhold regional dates | ICRISAT production handbook describes moisture, temperature and cultivar sensitivity. A 2025 rainforest sowing trial is location-specific and does not justify all Humid Forest LGAs. Need a traceable recommendation for the intended cultivar and zone. |
| Millet | Withhold regional dates | NAERLS public practices index truncates the planting text. That excerpt does not support a month-by-zone recommendation; full practice details and maturity class still need verification. |
| Irish potato | Withhold regional dates | NAERLS Irish potato practice page truncates dry-season instructions. It does not establish a transferable highland/lowland calendar in the accessible text. Need site temperature/elevation, variety and irrigation scope. |
| Tomato | Withhold regional dates | NIHORT guide supports cultivar, nursery/transplant and seasonal-water distinctions. NAERLS Tylka mentions location-dependent months without enough geography for all zones. Need sowing versus transplant dates, variety, water and location. The listed NIHORT 2023 edition still needs full inspection. |
| Yam | Withhold regional dates | IITA seed-yam research describes different propagation/harvest systems and variety-dependent maturity. This does not establish one planting calendar for ware yam across zones. Need species, seed/ware production and dormancy/establishment scope. |

Plantain and okra retain general care guidance; they are not newly added to the date calendar. No regional harvest dates are approved by this review. Harvest estimates need planting date, named variety/maturity and field readiness; multiplying a broad maturity range into region-only months would create false precision.

## Source register and access

- [IITA cassava illustrated guide](https://www.iita.org/wp-content/uploads/2016/06/Growing_cassava_commercially_in_Nigeria_an_illustrated_guide.pdf): indexed p8 Step 6 inspected; direct PDF fetch failed. The upload path is not asserted as the publication year. Seasonal pattern is a condition, not inferred from LGA alone.
- [IITA soybean guide, revised 2020](https://www.iita.org/wp-content/uploads/2020/07/Guide-to-Soybean-Production-in-Northern-Nigeria..pdf): indexed p7 Table 2 and edition citation inspected; direct PDF fetch failed.
- [IITA cowpea guide, 2020](https://biblio.iita.org/documents/U20BkOmoiguiCowpeaNothomNodev.pdf-c0c4714c7c29354d2ee191210918d6c2.pdf): indexed p7 Table 1 inspected. [NAERLS planting article](https://nfhl.naerls.gov.ng/index.php?solution_id=1068), May 2024, directly inspected for corroboration. The source's generic rainfall months are not presented as current forecasts.
- [NAERLS FARO 67 planting methods](https://nfhl.naerls.gov.ng/index.php?action=faq&artlang=en&cat=41&id=52) and [AfricaRice RiceAdvice](https://www.africarice.org/innovations/riceadvice): accessible official guidance; no inferred blanket date range.
- [ICRISAT sorghum handbook](https://oar.icrisat.org/11531/1/Handbook%20on%20Sorghum%20production%20for%20NE%20printed%20version.pdf): indexed cultivation section inspected; direct PDF returned 403. [2025 rainforest trial](https://oar.icrisat.org/13376/): abstract inspected, no extrapolation beyond trial scope.
- [NAERLS practices index](https://kms.naerls.gov.ng/agropractice/index): millet planting text truncated. [Irish potato practices](https://kms.naerls.gov.ng/variety/viewdetails/168): planting details also truncated; not treated as full evidence.
- [NIHORT tomato guide](https://nihort.gov.ng/wp-content/uploads/2020/07/PRODUCTION-GUIDE-ON-TOMATO.pdf): indexed cultivar and transplant sections inspected. [NIHORT manual directory](https://nihort.gov.ng/production-manuals/) lists a 2023 guide; directory listing alone is not review of that edition.
- [IITA-hosted yam propagation research, 2015](https://biblio.iita.org/documents/U15ArtAighewiImprovedInthomNodev.pdf-a5060575e242225ab45dbc8baeecab0c.pdf): indexed propagation/maturity section inspected; no zone-specific planting recommendation established.

## Remaining work

Obtain complete scoped sources for the six withheld crops and unsupported zones, inspect newer editions where available, resolve the cowpea Southern Guinea issue, and have a qualified local reviewer assess source applicability. Field checks should record location, season, variety, water regime and outcomes. The original 277 unsubstantiated calendar rows stay withheld.
